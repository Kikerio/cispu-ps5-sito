# Cispu PS5 Tracker

Prezzi, bundle e alert delle PS5 nei negozi svizzeri (CHF).

- Sito: pubblicato in automatico da GitHub Pages a ogni modifica.
- Prezzi: aggiornati ogni giorno alle 07:30 (ogni 30 min nella Black Friday Week) da `.github/workflows/deploy.yml`.
- Soglie degli alert Telegram: in cima a `scripts/scan.mjs`.
- Offerte, link e foto: `public/data/offers.json` (o il pulsante "Aggiungi / Modifica Foto Offerta" nell'app).
